Settings

Downloads Canva templates at a safe and steady pace, packed into ZIP files.

Check this if you are logged into Canva with a Canva Pro subscription. Allows downloading premium templates.

When enabled, only premium templates are selected and queued (free templates are ignored/skipped).

Start with 50 to 100 per day in the first week. Raise it only if Canva shows no warnings.

Import links from a file

A .txt or .csv file with Canva template links. All links found in the file are added.

Queue management

Clear all templates from the active queue with one click.
